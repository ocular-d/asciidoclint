== Rule Configuration Examples

The heading-spacing rule supports various configuration options:

=== Basic Configuration

[source,json]
----
{
  "rules": {
    "heading-spacing": "warning"
  }
}
----

=== Advanced Configuration

[source,json]
----
{
  "rules": {
    "heading-spacing": ["error", {
      "requireBefore": true,
      "requireAfter": true,
      "exceptions": [3],
      "allowConsecutiveHeadings": false
    }]
  }
}
----
