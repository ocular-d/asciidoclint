= Usage

[.lead]
AsciiDocLint provides a command-line interface and a programmatic API for integrating linting into your workflow.

== Command-Line Interface

Use the CLI to lint one or more AsciiDoc files directly from your terminal.

=== Basic Usage

[source,bash]
----
adoc-lint document.adoc
----

=== Multiple Files

[source,bash]
----
adoc-lint doc1.adoc doc2.adoc doc3.adoc
----

=== Glob Patterns

[source,bash]
----
adoc-lint docs/**/*.adoc
----

=== Piping Content

[source,bash]
----
cat document.adoc | adoc-lint
----

== Configuration

Pass a configuration file to override default rule settings.
See xref:configuration.adoc[Configuration] for the full schema, file discovery order, and severity levels.

=== Using a Configuration File

[source,bash]
----
adoc-lint --config adoc-lint.json document.adoc
----

=== Output Formats

[source,bash]
----
# Text output (default)
adoc-lint document.adoc

# JSON output
adoc-lint --format json document.adoc
----

== Programmatic API

Use the programmatic API to integrate linting directly into build scripts, editors, or custom tooling.
See xref:api-reference.adoc[API Reference] for the full type definitions and method signatures.

[source,javascript]
----
import { AsciiDocLinter } from '@testthedocs/core';
import { loadStandardRules } from '@testthedocs/rules-standard';

const linter = new AsciiDocLinter({
  rules: {
    'max-line-length': ['warning', { maxLength: 80 }],
    'heading-spacing': 'warning'
  }
});

loadStandardRules(linter);

const result = await linter.lintFile('my-document.adoc');
console.log(result);
----

== Exit Codes

* `0`: No issues found, or only info-level messages
* `1`: Configuration error, file not found, or runtime error
* `2`: Error-level or warning-level issues found (depending on `--quiet` and `--max-warnings`)
