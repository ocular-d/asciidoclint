= Usage

[.lead]
AsciiDocLint provides a command-line interface and a programmatic API for integrating linting into your workflow.

== Command-Line Interface

Use the CLI to lint one or more AsciiDoc files directly from your terminal.

=== Basic Usage

[source,bash]
----
adoc-lint document.adoc
----

=== Multiple Files

[source,bash]
----
adoc-lint doc1.adoc doc2.adoc doc3.adoc
----

=== Glob Patterns

[source,bash]
----
adoc-lint docs/**/*.adoc
----

=== Piping Content

[source,bash]
----
cat document.adoc | adoc-lint
----

== Configuration

Pass a configuration file to override default rule settings.

=== Using a Configuration File

[source,bash]
----
adoc-lint --config adoc-lint.json document.adoc
----

=== Output Formats

[source,bash]
----
# Text output (default)
adoc-lint document.adoc

# JSON output
adoc-lint --format json document.adoc
----

== Programmatic API

[source,javascript]
----
import { runRules, loadRules } from '@testthedocs/asciidoc-linter';

const content = `= My Document
Some content here.`;

const rules = await loadRules();
const config = {
  'max-line-length': { max: 80 },
  'heading-spacing': true
};

const issues = runRules(content, rules, config);
console.log(issues);
----

== Exit Codes

* `0`: No issues found
* `1`: Configuration or runtime error
* `2`: Linting issues found
