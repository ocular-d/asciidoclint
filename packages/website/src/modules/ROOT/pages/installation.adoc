= Installation
:node-min-version: 18.0.0
:pnpm-min-version: 8.0.0
:asciidoclint-version: 1.0.0

== Prerequisites

* Node.js {node-min-version} or later
* pnpm {pnpm-min-version} or later (recommended)

== Installing from npm

[tabs]
====
pnpm::
+
[source,bash]
----
pnpm add @testthedocs/asciidoc-linter
----

npm::
+
[source,shell]
----
npm install @testthedocs/asciidoc-linter
----

yarn::
+
[source,shell]
----
yarn add @testthedocs/asciidoc-linter
----
====

== Global Installation

For command-line usage, install globally:

[source,bash]
----
pnpm add -g @testthedocs/asciidoc-linter
----

== Verify Installation

Run the following command to confirm the installation succeeded:

[source,bash]
----
adoc-lint --version
----

.Output
[literal]
----
node bin/cli.js --version
{asciidoclint-version}
----

[#development-installation]
== Development Installation

To install for development:

[source,bash]
----
git clone https://github.com/ocular-d/asciidoc-linter.git
cd asciidoc-linter
pnpm install
pnpm run build
----
