= AsciiDoc Linter

Welcome to the AsciiDoc Linter documentation!

[.lead]
The AsciiDoc Linter is a minimal, extensible tool for linting AsciiDoc documents.
It helps ensure consistency and quality in your documentation by checking for common issues and style violations.

== Features

* **Extensible rule system**: xref:contributing.adoc[Extend with custom rules] without modifying the core engine
* **Configurable**: xref:configuration.adoc[Customize rules and their settings] per project or document type
* **Fast**: Built with TypeScript and Node.js for performance
* **CLI and programmatic API**: xref:usage.adoc[Use from the command line] or xref:api-reference.adoc[integrate into your build process]

== Quick Start

See the xref:installation.adoc[Installation] page for all install options, including npm, yarn, and global installs.

.Install the CLI
[source,bash]
----
pnpm add -g @testthedocs/asciidoc-linter
----

.Lint a document
[source,bash]
----
adoc-lint my-document.adoc
----
