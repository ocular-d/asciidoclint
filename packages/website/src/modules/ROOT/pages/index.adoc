= AsciiDoc Linter

Welcome to the AsciiDoc Linter documentation!

[.lead]
The AsciiDoc Linter is a minimal, extensible tool for linting AsciiDoc documents.
It helps ensure consistency and quality in your documentation by checking for common issues and style violations.

== Features

* **Extensible rule system**: Extend with custom rules without modifying the core engine
* **Configurable**: Customize rules and their settings
* **Fast**: Built with TypeScript and Node.js for performance
* **CLI and programmatic API**: Use from the command line or integrate into your build process

== Quick Start

.Installation
[source,bash]
----
pnpm add @testthedocs/asciidoc-linter
----

.Basic Usage
[source,bash]
----
adoc-lint my-document.adoc
----
